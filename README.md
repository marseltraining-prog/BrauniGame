# Хлебная карта Уфы

Браузерный экономический симулятор сети пекарен в Уфе. Старт — 10 млн ₽, цель — оборот 5 млрд ₽ за 12 месяцев (сильный игрок доходит примерно за 13–15 игровых лет и 40+ точек).

## Что внутри

- `src/config.js` — все числа баланса
- `src/data/world.js` — районы Уфы, соседство, продукты, оборудование
- `src/data/events.js` — 100 событий (70% негативных, 30% позитивных) + 5 кризисов
- `src/engine.js` — логика игры без интерфейса
- `src/ui/` — карта, панели, модальные окна
- `sim/bot.js` — боты для проверки баланса: `node sim/bot.js good 5 20`
- `qa/` — Playwright-тесты интерфейса
- `GDD.md` — дизайн-документ

## Сборка

```
node build.js
```

Собирает всё в один файл `dist/khlebnaya-karta.html` (для публикации) и `dist/local.html` (открывается в браузере напрямую).
