# Хлебная карта

**Версия 0.9.20 (бета) · сборка 08.10.2026 08:06 UTC** <!-- bk:version -->

> Версия и дата сборки обновляются автоматически при `node build.js`. Номер версии живёт в `BK.CFG.VERSION` (`src/config.js`), в игре он виден в правом верхнем углу рядом с переключателем темы и в «Меню игры».

Браузерный экономический симулятор сети пекарен: от бариста и своей кофейни до сети по России. На старте выбираются герой и один из 19 городов (по умолчанию Уфа); Москва и Петербург открываются после первого законченного прохождения. Старт — 10 млн ₽, цель — оборот 5 млрд ₽ за 12 месяцев (сильный игрок доходит примерно за 13–15 игровых лет и 40+ точек).

## Что внутри

- `src/config.js` — все числа баланса
- `src/data/world.js` — районы Уфы, соседство, продукты, оборудование
- `src/data/events.js` — базовые события и живые цепочки последствий + 5 кризисов
- `src/engine.js` — логика игры без интерфейса
- `src/ui/` — карта, панели, модальные окна
- `sim/bot.js` — боты для проверки баланса: `node sim/bot.js good 5 20`
- `qa/` — Playwright-тесты интерфейса
- `GDD.md` — дизайн-документ
- `PLAN.md` — актуальная очередь задач
- `HANDOFF.md` — состояние для передачи другому агенту
- `tools/check-release.js` — последовательные проверки релиза (отчёт в `docs/releases/`)

## Сборка

```
node build.js
```

Собирает всё в один файл `dist/khlebnaya-karta.html` (для публикации) и `dist/local.html` (открывается в браузере напрямую).

`NODE_PATH=~/.bk-tools/node_modules node build.js --min` дополнительно создаёт сжатый фрагмент и полный `dist/khlebnaya-karta-<версия>.html` для скачивания. Готовые версии и HTML — в [GitHub Releases](https://github.com/marseltraining-prog/BrauniGame/releases).

Екатеринбург в 0.9.10 получил подробную карту районов, улиц, прудов и мостов; Казань была проработана в 0.9.9. Старые сохранения сохраняют прежнюю географию. Результаты проверки и передача работы — [HANDOFF.md](HANDOFF.md).
