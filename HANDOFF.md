## Что это
Браузерный экономический симулятор сети пекарен: старт в Уфе (10 млн ₽, цель — 5 млрд ₽ оборота за 12 мес., сильный игрок ~15 лет), затем второй акт «Россия» — города, директора, корпорация. Весь интерфейс на русском. Один HTML-файл, без фреймворков.

- Репозиторий: https://github.com/marseltraining-prog/BrauniGame, ветка **main**.
- Игра для владельца (Artifact): https://claude.ai/artifact/B34cjJvLrqSpYXVN73kKkM (обновлять **по этой же ссылке**, передавая `url`).

## Правила работы (владелец так просил)
- После каждого значимого шага: `node build.js` → тесты → commit → push в **main**.
- Тесты (Playwright/Chromium предустановлен, `playwright install` не запускать; перед node: `export NODE_PATH=/opt/node22/lib/node_modules`):
  `node qa/smoke.js qa/shots`, `node qa/full.js`, `node qa/extras.js`, `node qa/russia.js`, `node qa/tutorial.js` — ждать «0 проблем, 0 ошибок консоли» (каждый идёт 1–5 мин, запускать по одному);
  боты: `node sim/bot.js good 3 18` (первый акт — должен оставаться побайтно прежним), `node sim/newbie.js 8 2`, `node sim/corp.js 2 16`, `node sim/bot.js good 6 24 --corp`.
- Числа баланса — в `src/config.js`. Не переименовывать экспортируемые функции и поля состояния (на них сохранения игроков). Всё новое в состоянии — с безопасными значениями по умолчанию; старые сохранения должны грузиться.
- Работали параллельными агентами в отдельных worktree, затем слияние в main. **Лимит подписки владельца** кончался дважды при 3–5 агентах одновременно — лучше 1–2 агента за раз.

## Публикация (важно)
Собранный файл ~820 КБ; в Safari у владельца был белый экран на несжатой версии. Сейчас публикуется **сжатая** версия (~590 КБ):
1. `node build.js`
2. сжать JS terser'ом (`npm i --no-save terser` во временной папке) и CSS (убрать комментарии и пробелы) из `dist/khlebnaya-karta.html` — скрипт `tools/minify.js` (см. шапку файла) → `dist/khlebnaya-karta.min.html`.
3. опубликовать сжатый файл по URL выше.
Подтверждения от владельца, что Safari теперь работает, ещё нет — спроси. Если не работает: проверить в WebKit, ещё уменьшить размер (например, вынести данные городов), проверить localStorage в Safari.
Хорошо бы встроить сжатие прямо в `build.js` (например, `node build.js --min`).
