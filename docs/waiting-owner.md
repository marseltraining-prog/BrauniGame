## Ответ владельца на вопрос 3 (04.10.2026): семья — вариант (б) с уточнениями

- **Линии должны быть прозрачными**: игрок заранее видит, что линия идёт и к чему подводит (предупреждение в «Требует внимания» / «Сводке»), а не узнаёт постфактум.
- **Болезнь**: показывать переживание, тревогу, выбор «успеть / найти деньги / сделать дела» — но **без открытой больницы**, без больничных подробностей.
- **Смерть близкого**: только через **заставку** — грустная 8-битная музыка, медленно темнеющий экран, намёк вместо показа: например, **врач, который качает головой**. Прямого показа нет.
