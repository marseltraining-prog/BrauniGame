# Статистика игры

Счётчик Яндекс Метрики: **113767534**. Публичная страница — `https://marseltraining-prog.github.io/BrauniGame/play/`.

## Где смотреть

1. `metrica.yandex.ru` → выбери счётчик «Хлебная карта».
2. **Отчёты → Посещаемость**: визиты, посетители, устройства, источники.
3. **Цели**: `play_start`, `continue_game`, `act_russia`, `holding_ipo`, `holding_abroad`,
   `holding_franchise`, `win`, `ending_*`.
4. **Сводка**: сколько заходов и сколько из них начали играть.

## Что означает

- Заход без `play_start` — открыли и ушли.
- `play_start` — начали новую партию.
- `act_russia` — дошли до второго акта; лучший показатель «играют по-настоящему».
- `win` — победили первый акт.
- Концовки — какой финал выбрали.
