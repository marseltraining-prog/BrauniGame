# Изолированный черновик Самары

`city-samara.js` — кандидат для будущего `src/data/city-samara.js`; он не подключён к игре, сборке или симулятору. Источники, состав, экономика, ограничения и порядок интеграции находятся в `docs/samara-map-sources.md`.

Состав: 10 игровых зон, 60 улиц, 40 POI, Волга и Самара, 3 автомобильных моста через Самару, 18 дорожных линий, 8 зелёных пятен, 2 условных железнодорожных линии. Экономика следует существующим образцам; коэффициенты Самары остаются в CITIES.samara. Старые архетипы сохранены; добавлен Куйбышевский/far.

Чтение исходников и официальных web-источников, создание только изолированного data-файла и документации. Никакие runtime, тесты, боты, Engine, браузеры, сборки или публикации не запускались. До принятия проверок география остаётся черновой; её нельзя называть точной картой административных районов.
