# Изолированная защита выбора

Подготовлено для пункта 4. Реальные src/sim/qa не изменялись. Никакие игры, тесты, браузеры или сборки не запускались. Пройдены только node --check трёх файлов и git apply --check.

После завершения текущего прогона родитель применяет guard.patch и копирует sim/story-choice-guard.js в настоящий sim/. CLI sim/story.js родитель подключает отдельно: функция needOk(S,R,need) должна делегировать BK.Story.canChoose(S,need), сохраняя существующую сигнатуру вызовов. Новый тест подключить к последовательному release runner.

В тесте 15 комбинаций требований × 2 пола × 3 вида окна (несколько вариантов, один вариант, письмо), границы rel/meter −1/точно/+1, составные требования с отказом каждого отдельного поля; реальные Rewind.take/JSON загрузки, сохранённое pending, полностью неизменный state/RNG после запрещённого прямого resolve, последующее легальное разблокирование того же окна, реальные последствия/случайная очередь один раз, отсутствие повторной выплаты после reload и once/fits. Реальная сцена sf1b проверяется для отсутствующего Рашида и ушедшей Гули при высоких отношениях.

Ограничения: синтетический fixture изолирует предикат и не доказывает достижимость всех сцен; это задача allBranches. Renderer adapter проверяет настоящий HTML и disabled, но не геометрию браузера. Rewind.take используется как настоящий сериализатор сохранения; UI Rewind.restore и сохранение localStorage этим тестом не покрыты. Семейный famPick вне области Story.resolve.
