# Изолированная очередь сюжета

Патч не применён. Проверки не запускались: родитель выполняет последовательную проверку ветвей.

- `story.patch`: только start, due-очередь и исключение queueOnly из natural fallback; удаление мёртвого fallback у sf1 и исправление комментария.
- `sim/story-queue.js`: новый regression через реальный Story/Engine/Rewind. Перенести в sim/ после применения патча и запустить последовательно.
- При pending следующий due не меняет срок, не теряется и не создаёт новое уведомление. За day начинается максимум одна сцена. Неповествовательные очередные записи обрабатываются прежним порядком.
- При открытом событии, недавнем событии или окне шефа сохранена отсрочка +2 дня; добавлен отсутствовавший guard открытого события.
- Старый дубль одноразовой сцены удаляется без повторного эффекта; once:false остаётся повторяемым.

## Финал sf1

Фактическое правило игры: после победы S.won очередь ставит sf1 на S.day + 30, только один раз через wonQueued. Окно может прийти позже из-за уже открытого сюжетного решения, события или шефа. Расширения финала нет.

«Финал без победы через 18 лет» — историческая неисполненная идея в комментарии данных, не завершённое требование. `trigger.fallback` не читается: generic pick использует `sc.fallback`, а sf1 queueOnly. Патч удаляет ложный fallback и обещание. Все queueOnly исключены и из второй fallback-петли: иначе будущий верхнеуровневый fallback мог бы обойти явное планирование очередью. Родителю нужно согласовать текст PLAN/GDD с фактическим won+30 и сохранить историческую идею отдельно, если она нужна.

Механика существующей won-очереди и финальные варианты не изменены. Другой агент меняет need/resolve/UI; данный патч этих функций не касается.
