# Гербовые рисунки на экране выбора города

Дата проверки источников: 4 октября 2026 года.

`src/data/city-arms.js` содержит 19 самостоятельно нарисованных контурных интерпретаций городских гербов. Они используют общий щит и палитру карты (`currentColor`, `--crust`, `--map-river`). Это художественная стилизация для игры: официальные геральдические цвета, короны, щитодержатели, наградные ленты и мельчайшие детали сознательно не воспроизводятся. Исходные фотографии и чужие SVG не копировались, внешние ресурсы не загружаются.

Первичные основания — муниципальные страницы и тексты решений городских дум. Для пяти городов описание взято из текста муниципального решения в правовой базе: такие ссылки ниже явно обозначены как перепечатки первичного документа, а не как страницы администрации. Страница «Дизайн-кода Екатеринбурга» — первичный источник создателей современной городской отрисовки.

API `BK.cityArms(id)` возвращает внутреннюю SVG-разметку под `viewBox="0 0 160 180"`. Он не меняет выбранный город, сохранение или генератор случайных чисел. Нет `id`, `defs`, событий, вложенных скриптов или внешних ссылок: один рисунок можно безопасно показывать одновременно в карточке, поле выбора и мобильном превью. Неизвестный идентификатор возвращает Уфу.
