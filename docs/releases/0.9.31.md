# 0.9.31 «бета» — пролог без свистка

Правка по отзыву владельца: в прологе высокий треугольный тембр звучал как дудка и перекрывал всё остальное.

## Что изменено

- Мелодия пролога **опущена на октаву** (trans −12), громкость снижена с 0,30 до 0,17.
- Фильтр пролога стал глуше: 2350 → 1750 Гц; подложка и бас, наоборот, чуть слышнее — музыка стала мягче,
  а не «одна дудка поверх всего».
- Во всех составах мелодия приглушена (0,32 → 0,23 в сети, 0,32 → 0,24 в России, 0,28 → 0,20 в холдинге),
  подложка аккордов добавлена. Победная тема тоже стала мягче (0,36 → 0,27).
- В тестах регистр пролога теперь проверяется как «ниже игры, не свистит», а не «выше» — это осознанное
  изменение после отзыва.
