# 0.9.16 «бета» — игра без интернета и честный перенос открытия

**Игра работает полностью без интернета.** Шрифты Golos Text, Unbounded и JetBrains Mono теперь лежат внутри файла игры (`src/fonts/`, встраивает `build.js`): кириллица, латиница, знак ₽ и башкирские/татарские буквы. В собранной игре нет ни одного сетевого адреса — проверено в Chromium с отключённой сетью. Скачанный HTML выглядит без сети так же, как с ней. Файл вырос примерно на 260 КБ. С настоящими шрифтами в тестах нашлось обрезанное имя сети в верхней полосе на ноутбуке 1280 px — исправлено.

**«Воскресный ужин» (сцена s22) переносит открытие по-настоящему.** Раньше выбор «перенести открытие» только записывался, а точка открывалась в прежний день. Теперь пятая точка открывается на 3 дня позже вместе с её начальной командой и подключением доставки; сцена называет настоящие даты из календаря игры. Если пятая уже работает — разговор просто о семейном ужине, без переноса. Проверка — `node sim/defer-open.js` (24), аудит сюжета сверяет дату открытия.

Проверки выпуска шли в облаке (claude.ai/code): там нет WebKit, поэтому проверки `@webkit` не запускались — их нужно прогнать на Mac владельца (`node tools/check-release.js --retry-failed`). Замечания о долгих задачах при замедлении CPU×4 в `qa/full.js` / `qa/pixel.js` — особенность медленной облачной машины, они были и на сборке до изменений. Отчёт раннера — `docs/releases/0.9.16-checks.json` (58/73: 12 провалов — WebKit не установлен, 2 — замечания CPU×4). Две проверки, не уложившиеся в 12-минутный лимит раннера на облачной машине, прогнаны отдельно без лимита: `sim/story.js --all-branches 1 22 --snapshots` — код 0 (1061 с), `qa/story-branches.js` — 11158 проверок, 0 проблем. Канонические боты первого акта побайтно прежние.
