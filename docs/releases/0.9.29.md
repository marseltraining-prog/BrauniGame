# 0.9.29 «бета» — честная статистика продуктов в городах на автопилоте

Небольшой выпуск про честность цифр. В городах второго акта, которые переведены на автопилот, статистика
продуктов не обновляется — она замирает на дате перехода. Раньше окно показывало её как свежую; теперь
подписано, за какой момент данные.

## Что изменилось

- В окне шеф-пекаря и во вкладке «Меню» для упакованного города появляется пометка **«данные на момент
  перехода города на автопилот»**. Оценка «примерно» осталась: по продуктам продажи делятся по модели спроса.
- Для домашнего города и для города, который сейчас ведётся вручную, ничего не изменилось.
- Обновлено описание репозитория на GitHub — теперь 0.9.29, а не 0.9.15.
