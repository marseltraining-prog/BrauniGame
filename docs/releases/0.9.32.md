# 0.9.32 «бета» — статистика заходов и игры

Подключена Яндекс Метрика, счётчик **113767534**. Считает заходы на публичную страницу и ключевые шаги игры.
Работает **только на `marseltraining-prog.github.io`**: локальный файл, тесты и офлайн-игра не делают
сетевых запросов.

## Что считается

- **Заход** — открытие страницы (Метрика сама).
- **`play_start`** — новая партия (кнопка «Новая игра», пролог, «Сразу Россия»/«Сразу холдинг»).
- **`continue_game`** — вернулись в сохранение.
- **`act_russia`** — первый вход в город второго акта.
- **`holding_ipo` / `holding_abroad` / `holding_franchise`** — выбран путь холдинга.
- **`win`** — победа первого акта.
- **`ending_*`** — какая концовка получена.

Цели видны в Метрике: «Цели» → `play_start` и остальные. Заходы, устройства, география и время — в
«Отчёты» → «Посещаемость».

## Что важно

- Плашка про cookie появляется один раз; кнопка «Понятно» запоминается.
- `webvisor` выключен: запись экрана/ввода не ведётся.
- Если счётчик не загрузился (офлайн, блокировщик), игра работает как раньше.
- Для локальной проверки статистика отключена по домену; тесты не ходят в интернет.

## Проверки

Локальная страница: `BK.Analytics.on === false`, запросов к `mc.yandex.ru` нет. Публичная — счётчик
загружается, цели отправляются. Полный прогон — `docs/releases/0.9.32-checks.json`.
